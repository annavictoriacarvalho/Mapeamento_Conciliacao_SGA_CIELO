1. Entrada de Dados

1.1. Recebimento do Relatório da Maquininha Cielo

Responsável acessa o sistema da maquininha Cielo.

Gera e exporta o relatório diário.

O relatório deve conter:

Data da transação

Valor pago

Código do procedimento

Número da autorização junto ao Sistema SGA.

Forma de pagamento (crédito/débito/ pix e dinheiro. 


2. Organização das Informações

2.1. Classificação das Transações

Separar transações por:

Procedimento

Forma de pagamento

Data

Valor


Conferir se todos os procedimentos estão com código correto.


2.2. Identificação dos Registros Internos

Acessar o sistema interno (SGA, financeiro ou outro).

Localizar os lançamentos correspondentes usando:

Código do procedimento

Nome do paciente/cliente

Data

Valor do atendimento

3. Conciliação

3.1. Comparação dos Valores

Verificar se valor do relatório = valor registrado no sistema para cada código.

Caso haja divergência:

Registrar em planilha própria

3.2. Verificação do Código do Procedimento

Confirmar se:

O código lançado no sistema corresponde ao código exibido no relatório da Cielo.

Ajustar em caso de código incorreto ou trocado.

3.3. Conferência da Data

Verificar se a data da transação está dentro do período correto.

Corrigir lançamentos fora do período.

4. Validação Final no sistema

4.1. Geração de Relatório de Conciliação

Emitir uma planilha ou relatório contendo:

Quantidade total de transações

Valores conciliados

Divergências encontradas

Ajustes realizados


4.2. Aprovação

Enviar relatório para o responsável pelo financeiro para validação.

5. Encerramento do Processo

5.1. Arquivamento

Salvar:

Relatório da maquininha

Relatório final de conciliação

Registros ajustados.
